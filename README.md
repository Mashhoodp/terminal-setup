# Terminal Setup Script

This script, **`terminal-install.sh`**, automates the installation and configuration of a modern Linux terminal environment.

## ✨ What it does

- Installs essential tools: `git`, `zsh`, `tmux`, `alacritty`, `bat`, `fzf`, `neovim`, and more.
- Sets up `zsh` with plugins (syntax highlighting, completions, autosuggestions, fzf-tab).
- Installs the Starship prompt and my dotfiles.
- Clones `NVChad` for Neovim.
- Installs Tmux Plugin Manager and plugins.
- Copies JetBrains Mono fonts and refreshes font cache.

## ⚡ Usage

```bash
git clone https://github.com/Mashhoodp/terminal-setup
cd terminal-setup
chmod +x terminal-install.sh
./terminal-install.sh
```
