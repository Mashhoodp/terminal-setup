# Terminal Setup Script

A script to set up my terminal environment on **Arch Linux**, **Debian**, or **Kali**.

---

## Tools Included

It installs the following:

- **Shell**: zsh with tmux and git  
- **Terminals**: alacritty and ghostty  
- **Editor**: neovim (latest version)  
- **Prompt**: starship  
- **Utilities**: lazygit, fzf, bat  
- **Zsh Plugins**:
  - Autosuggestions
  - Syntax Highlighting
  - FZF-Tab

---

## Usage

```bash
git clone https://github.com/Mashhoodp/terminal-setup
./terminal-setup.terminal-install.sh
```
